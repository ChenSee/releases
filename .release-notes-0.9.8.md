# TrueAsync PHP 0.9.8 (php 8.6)

A patch on 0.9.7: php-src and php-async are the same builds, and only the HTTP
server moves, from `v0.13.0` to `v0.14.0`. Nothing in this release breaks a
build that ran on 0.9.7.

## Highlights

- **`awaitWritable()` waits on HTTP/3.** The call answered false for any full
  stream, because the HTTP/3 transport declared no way to wait — while HTTP/1,
  HTTP/2 and the reactor-pool worker all park the handler until the queue
  drains. A handler was left with a sleep-and-retry loop, which on a pool worker
  holds the thread that is carrying the other requests.
- **A response aborted before its first byte no longer reports itself as
  cleanly ended.** `abort()` on a stream the transport had nothing on the wire
  to fail left the response labelled the way `end()` leaves it, so a second
  `abort()` threw — inside the `catch` block where that replaces the error the
  handler was already carrying.
